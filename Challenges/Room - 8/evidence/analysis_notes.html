MIRA-7 Implant - Config Notes
Room 8 // sealed config v1

The implant keeps its settings sealed under an RSA public key. A crash handler dumped part of the matching private key when the sample died in the sandbox. Everything is hex. Nothing here says how to use it; that part is yours.

Key material

itemvalue
nthe modulus, in sealed_config.json
e65537
pthe larger of the two primes that make up n
leak.p_highp with its low bits set to zero. The zeroed bits are the ones the dump could not read
notethe dump stops at the point where the crash handler lost the rest

Sealed config

itemvalue
schemeRSA-OAEP
hashSHA-1, with MGF1-SHA-1
labelnone
ciphertexthex, in sealed_config.json as ct
plaintexta flag in NIGHTJAR{...} form

Answer formats

targetformat
8.1NIGHTJAR{zero_bits_N}, where N is the number of zero bits at the bottom of leak.p_high
8.2NIGHTJAR{p_XXXXXXXXXXXXXXXX}, the last 16 hex digits of p, lowercase
8.3the flag stored in the sealed config
8.4NIGHTJAR{q_XXXXXXXXXXXXXXXX}, the last 16 hex digits of q, lowercase

Check that your p divides n before you trust it. Several wrong candidates look right.
