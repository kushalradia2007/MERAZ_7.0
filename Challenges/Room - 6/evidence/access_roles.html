The database mirror is the same archive used for the volunteer records. Three catalog tables describe database access control: database_roles, role_permissions and role_members. The permission matrix is not rendered here; build it from the data.

Security review notes are stored as encrypted PDFs. Policy for these documents: each review is locked with the name of the role it covers.
