IDOR  Volunteer Profile Enumeration

The volunteer portal exposes profiles at /portal/profile/:id. The server never checks whether the logged-in user owns that ID. Enumerate profiles to find the hidden one whose access tier grants INFRA access without a completed orientation.

Change the ID below and click SEND REQUEST. IDs run from 1 to 200. One profile is special — keep looking.

GET /portal/profile/ Authorization: Bearer <your_session_token>

IDs are sequential integers. Most return a normal profile. One ID returns a profile whose access_tier is INFRA and orientation_complete is false. The flag is the value of the _flag field in that response.
